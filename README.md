# Time Series Project

A Python project for simulating and statistically validating
autoregressive time series models of arbitrary order, AR(p).

## Project Structure

- `models/autoregressive/simulation.py`: AR(p) simulation functions.
- `tests/test_ar.py`: Statistical validation tests.

## Tools

- Python 3.13
- NumPy
- pytest

## Status

Project structure initialized.
AR(p) simulation and statistical tests are under development.
